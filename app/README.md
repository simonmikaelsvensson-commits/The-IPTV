Android app skeleton (Kotlin)

Open this folder in Android Studio as a project. Files created are minimal skeletons to get started:
- app/src/main/AndroidManifest.xml
- app/src/main/java/com/theiptv/MainActivity.kt
- app/src/main/java/com/theiptv/network/ApiClient.kt

This is a starting point; open in Android Studio to generate full Gradle project files or import into an existing Android project.
